# Security Policy

## Project Status

Easecraft is currently in the proposal stage. There are no published packages, hosted applications, or supported releases yet.

This policy will be updated with a supported-version table and release-specific guidance before the first public package release.

## Reporting a Vulnerability

Do not disclose a suspected vulnerability in a public issue, pull request, discussion, or social media post.

Report it privately to the project maintainer using the contact information on the [Eswar2000 GitHub profile](https://github.com/Eswar2000). Include:

- The affected file, commit, package, version, or URL
- A clear description of the impact
- Minimal steps or a proof of concept that reproduces the issue
- Any known mitigations or workarounds
- Whether the issue has been disclosed anywhere else

Please omit unrelated personal data and credentials. You should receive an acknowledgment within seven days, followed by status updates as the report is investigated.

## Coordinated Disclosure

Please allow time to validate and address a report before publishing details. The maintainer will coordinate a disclosure date and credit with the reporter when appropriate.

## Out of Scope

General feature requests, non-security defects, and proposal feedback should use the repository's public issue templates.
